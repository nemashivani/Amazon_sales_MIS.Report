## Amazon Sales Report

## 📌 Project Overview
-This project analyzes Amazon sales data to identify key business insights using Power Query and Excel.

## 📊 Tools Used
- Microsoft Excel (Pivot Tables, Charts, Slicers,Dashboard)
- Data Cleaning & Data Analysis
- Power Query

## 📈 Key KPIs
- Total Sales
- Total Qty.
- Total Orders

 ### Key Features
- Data cleaning and transformation using Power Query
- Sales performance and KPI analysis
- Category and state-level reporting
- Management insights through dashboard visualizations


## 📊 Dashboard Features
- Monthly Sales Trend
- Category Report
- State wise Report
- Order Summary

## 🧠 Business Key Insights
1.Monthly sales performance: April recorded the highest sales among the display months.
2.Category wise performance: kurta was the leading product category by quantity.
3.State wise performance: Manipur recorded the highest sales contribution.
